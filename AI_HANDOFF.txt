NEW COMPUTER SETUP
==================

The project should be downloaded from GitHub. It does not need to be emailed.

Install first:

1. Git for Windows: https://git-scm.com/download/win
2. Node.js 20 LTS or newer: https://nodejs.org/
3. The preferred editor or AI coding tool.

Recommended clone commands:

  git clone https://github.com/MrtomerGG/GGNews.git
  cd GGNews
  npm install
  npm run dev

Then open:

  http://localhost:4321

Production verification:

  npm run build
  npm run preview

If using GitHub Desktop instead:

1. Open GitHub Desktop.
2. Select File > Clone repository.
3. Select URL.
4. Enter https://github.com/MrtomerGG/GGNews.git
5. Choose a local folder and clone.
6. Open PowerShell in the cloned folder.
7. Run npm install and npm run dev.

Downloading GitHub's ZIP is possible, but cloning is strongly preferred because a ZIP has no Git history and cannot pull or push changes normally.


SAFE START FOR EVERY AI/DEVELOPER SESSION
=========================================

Before editing:

1. Read this file, README.md, .pages.yml, and the relevant source files.
2. Run git status --short --branch.
3. Preserve any unrelated or uncommitted user changes.
4. Run git pull --rebase origin main before beginning if the worktree is clean.
5. Remember that Pages CMS may create new commits while local work is happening.

Before uploading code:

1. Run npm run build.
2. Inspect git diff and git status.
3. Commit only the intended files.
4. Run git pull --rebase origin main again to preserve recent Pages CMS changes.
5. Rebuild if remote content changed.
6. Push to origin/main.

Never use destructive Git commands such as git reset --hard to solve a conflict.


CONTENT AND PUBLISHING
======================

Article source files:

  src/content/articles/*.md

Uploaded article images:

  public/assets/uploads/

Article schema:

- title: required
- excerpt: required
- publishedAt: required
- updatedAt: optional
- author: required
- featured: true/false
- draft: true/false
- cover: optional image path
- youtubeId: optional 11-character YouTube video ID
- body: Markdown article content

Article behavior:

- Draft articles are hidden.
- The newest article marked featured is the large homepage story.
- If no article is featured, the newest published article is used.
- Keep only one intended featured article.
- Videos are part of their articles; there is no separate video section.
- Article covers appear behind the title on the homepage hero, the article page hero,
  and cards on the all-articles page.
- Articles without covers use the branded GGNEWS fallback.

Pages CMS publishing flow:

1. Sign in at https://app.pagescms.org/ with GitHub.
2. Open MrtomerGG/GGNews.
3. Open כתבות and create or edit an article.
4. Keep טיוטה enabled while drafting.
5. Save and merge the generated GitHub pull request if required.
6. When ready, disable טיוטה, save, and merge again.
7. Wait for Cloudflare's production deployment to report Success.
8. Verify the result at https://ggnews.club and hard refresh if necessary.

Pages CMS also controls:

- הודעת האתר: the dismissible announcement below the navigation.
- הגדרות התראות: the public OneSignal App ID and notification enable switch.

localhost and the public website are separate:

- localhost:4321 reads the files on the current computer.
- ggnews.club reads the latest successful Cloudflare deployment from GitHub main.
- After an online Pages CMS edit, run git pull origin main to update the local copy.

   secret name ONESIGNAL_APP_API_KEY.
3. Wait for a successful Cloudflare deployment.
4. Open https://ggnews.club in a normal browser window, click the GGNEWS bell,
   select הפעלת התראות, and allow browser notifications.

Automatic notification behavior:

- Creating a public article or changing draft from true to false triggers the workflow.

- The workflow waits for the article page to become live on Cloudflare before sending.
- The alert uses the article title, excerpt, cover, and final article URL.
